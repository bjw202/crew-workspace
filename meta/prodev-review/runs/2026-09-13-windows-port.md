## 3. 곁들여 잡은 것 — 윈도우와 무관한 결함 하나

`session-start` 훅이 일지 날짜를 **두 달력으로** 다뤘다.
- `어제()` 는 로컬 달력 (`getFullYear`/`getMonth`/`getDate`)
- `빈날` 은 UTC 자정 기준 (`Date.parse(끝 + 'T00:00:00Z')` 를 24시간으로 나눔)

일지 파일 이름은 봇이 `date` 로 오늘을 알고 짓는 로컬 달력이므로 세는 쪽도 로컬이 맞다.
섞여 있어서 한국(UTC+9)에서는 **자정부터 오전 9시 사이에** 어제 일지가 "0일 전" 으로 나왔다.
봇이 켜질 때마다 싣는 「며칠 비었나」 — "무엇을 놓쳤나" 의 첫 실마리로 쓰는 숫자 — 가 그 시간대에 하루씩 틀렸다.

**찾은 방식**: 작업 중 시계가 2026-09-13 00:11 KST 를 넘어가며 시험 하나가 붉어졌다.
내 고침 탓인지 가리려고 **손대지 않은 본 체크아웃(df2373a)에서 같은 시험을 돌려** 거기서도 붉는 것을 확인했다.
- 커밋을 따로 두었다(`1b98b53`). 이 하나만 되돌리면 윈도우 고침은 그대로 남는다.
- 시간대를 UTC 로 통일하는 쪽이 낫다는 판단이면(minidiscord 는 그 길을 갔다) 그것은 **설계**라 사람이 정한다.

## 5. 앞 세션의 진단 둘이 틀렸다

`../../WINDOWS-PORTING.md` 는 실제로 밟아 쓴 좋은 문서인데, **진단 둘이 틀렸다.** 고쳐 둔다 —
틀린 진단은 고칠 수 있는 자리를 가린다.

**① 7.2 "MSYS 셸이 native 실행 파일에 한글 인자를 넘길 때 코드페이지로 떨어뜨린다. 실전 영향 없다"**
→ 셸이 아니다. 갈리는 것은 **그 exe 가 argv 를 ANSI 로 읽는가**다. 넷을 갈라 재 봤다:

| | bash → | node execFileSync → |
|---|---|---|
| `System32\curl.exe` | 멀쩡 | 멀쩡 |
| `Git\mingw64\bin\curl.exe` | **깨짐** | **깨짐** |
| `python3` · `node` | 멀쩡 | 멀쩡 |

그리고 **실전 영향이 있었다.** 훅 알림이 방에 `????` 로 올라갔고 시험 셋이 그것을 잡고 있었다.
진짜 결함은 «어느 curl 이 잡히는지를 사람이 못 고른다» 는 것 — 같은 창에서 `curl` 은 System32 인데
`npm test` 안에서는 mingw 이 잡혔다(npm 이 PATH 를 다시 짠다). **PATH 순서가 방에 올라가는 글자를 바꿨다.**
그래서 3.5 의 PATH 순서를 문서로 지키는 대신 알림에서 curl 을 **뺐다**.

**② 6절 확인표 "npm test → 133 통과 · 실패 0"**
→ 그 판에서 실제로는 셋이 실패했다(위 ①). 통과로 적힌 채 넘어갔다.

**남길 교훈**: 진단을 적을 때 **갈라 보고** 적는다. ①은 "그럴 것이다"를 "그렇다"로 적은 것이고,
고칠 수 없는 자리(시스템 코드페이지)를 가리켜 **고칠 수 있는 자리(PATH 의존)를 가렸다.**

## 6. 사람이 정할 것 넷

1. **PR 로 올릴까.** 두 브랜치가 로컬에만 있다. `prodev` 는 `meta/CLAUDE.md` 대로 worktree + PR 이 맞고,
   `minidiscord` 도 같은 꼴로 두었다 (본 체크아웃은 안 건드렸다). push 는 안 했다.
2. **맥에서 시험 넷을 돌릴까** (4절 첫 줄). 그것이 «두 환경에서 다 돈다» 의 마지막 근거다.
3. **날짜 달력을 로컬로 둘까 UTC 로 갈까** (3절). 지금 커밋은 로컬이다. minidiscord 는 UTC 로 통일했다.
4. **`settings.template.json` 의 `Write(<경로>)` 규칙 넷을 지울까.** Claude Code 가 봇 세션마다
   "`Write(path)` 규칙은 파일 권한 검사에 안 쓴다" 고 경고한다. `Edit(...)` 짝이 나란히 있어 구멍은 없고
   경고만 시끄럽다. 지우면 허용 22건 → 20건이 되어 ADR-033 의 숫자와 시험 둘을 같이 고쳐야 한다.
   **포팅에 필요하지 않아 손대지 않았다.**
