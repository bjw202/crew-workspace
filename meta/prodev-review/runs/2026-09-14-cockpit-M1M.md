## 새 알림 N1~N6 에 대한 결정
| N | 결정 |
|---|---|
| 1 `<channel>` 속성의 `<` 도 `&lt;` | 승인. 속성 인코딩이지 값 변형이 아니다(`"` 와 같은 급). ADR-013 에 "meta 값은 속성 인코딩만" 으로 적는다 |
| 2 스크래치 경로에서 uploads `Read` 가 콜백으로 옴 | 기록. 실증 4h″ 와 같은 모양. **실전 경로에서도 그러면 들이기마다 승인이 뜬다** — W1.3(P-W1.11)에 "uploads 첨부 Read" 를 한 줄 더한다. cockpit 은 고치지 않는다 |
| 3 engines ≥ 22.13 | 승인. PRD N 항목도 22.13 으로 맞춘다 |
| 4 since_id 뒤 오래된 것부터 limit | 승인 |
| 5 M1 한정 전부 거부 | 승인 |
| 6 사본 돌리는 법 | 그대로 썼다. 한 가지: meta 의 보호 훅이 "prodev 경로 + `rm`/`npm ci`" 를 막으므로 스크래치 폴더는 이름을 새로 지어 만든다 |

## 빗나간 것 · 알아 둘 것
- m1-guard 는 모델이 지침을 지켜 재현이 안 된다. cockpit 에게: 스모크가 1000자 글을 **주고** "그대로 보내라" 로 한 번 바꿔 보고, 그래도 안 되면 스모크를 "재현 불가" 로 적고 접는다(막는 논리는 prodev 시험이 잡는다).
- meta 의 보호 훅이 `|truncate)` 같은 파이프 뒤 낱말도 쓰기로 본다(오탐). 훅 규칙은 그대로 두고 명령을 바꿨다.
