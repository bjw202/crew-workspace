## 새로 본 것 (판정 밖 · 다음 지시에 실을 것)
- **값 바닥(N11)**: `result` 의 `total_cost_usd` 는 같은 CLI 프로세스 안에서 누적이고(0.366 → … → 3.77, 사이의 `init` 사건 18개는 프로세스 교체가 아니라 턴마다의 system init), **재기동(stop → start) 뒤 0 부터**(0.528 → 1.608 → 1.690). `agent_sessions.cost_usd` = 정지 전 3.77 + 뒤 1.69 = **5.46** — cockpit 의 바닥 방식이 맞다. W2r.2 의 뜻("더하지 않는다")과 어긋나지 않는다: 프로세스 안에서는 덮어쓰고, 프로세스가 바뀔 때만 바닥을 올린다.
- 조종석 값 $5.46 대 cost.js 표준단가 $7.99 — 차이는 도우미(서브에이전트 32 호출)와 단가. 조종석 "추정치" 표시가 맞는 까닭이 하나 더 생겼다. SDK 값이 도우미 값을 싣는지는 cockpit 이 문서에 적어 두면 좋다(고침 아님).
- 압축 요청이 `queued:true` 로 3분 36초 뒤에 들어갔다. 대본의 "압축 뒤 프롬프트가 돌아오면" 을 API 로 대신할 때 **끝남 확인은 `events` 의 `compact` + `result` 와 state idle** 로 충분했다(8.3 의 표 그대로).
- 봇이 R2 에서 `ARCHITECTURE.md` 를 찾아 스크래치 전체와 `/Users` 를 `find` 로 뒤졌다(과제 밖 읽기 시도, 승인 카드 1). 왜 그 문서를 찾았는지는 세션 기록에 있을 것 — prodev 쪽 관찰.
- 인수인계서가 방1 의 마지막 message_id 를 "모름" 이라 적었다(prodev 훅 쪽, 조종석 무관).
- R4 의 브리핑(4-5)은 이번에도 대본 안에 안 왔다 — 조사는 11:01:51 에 끝났고(도우미 completed) 재기동 뒤 #45 에서 "reviewer 백그라운드 교차검증 중" 이라 알렸다. M3.M 채점 밖.
- 스모크 m3-restart 의 "첫 답에 이어서" 조항은 다음 채점표에서는 R5 5-5 로만 잰다고 적어야 한다(스모크 글이 답 머리를 정한다).
