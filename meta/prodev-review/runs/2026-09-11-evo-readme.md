- "여덟 가지" 에 S 번호를 새로 붙이지 않고 `subgraph V3` 로 갈라 PRD 의 F14~F18 · N8 · N9 를 가리킨 판단. 여덟은 "과제를 잇는 일", 셋은 "쓸수록 맞아 가게 하는 일" 이라는 한 줄이 v2 → v3 의 차이를 그림 하나로 보인다. **눈으로 본 한 줄: 처음 보는 사람이 구조 그림의 저장소 칸(`house.md` · `analysis/` · `templates/`)과 "여덟 가지 + 더한 셋" 그림 둘로 v3 가 무엇을 더했는지 안다.**
