## 3. 사람이 본 결함 둘 (M6 의 몫)
- **N17 도구 입력 요약 줄바꿈**: 접이식 판 "이번 턴 도구 호출" 의 `code.tool-input` 이 좁은 판에서 **한 글자씩 세로로** 떨어지는 카드가 있다(같은 판의 다른 카드는 정상 — 폭을 못 받는 flex 자식이 `min-width:auto` 로 눌린 꼴로 보인다). 고칠 자리는 `style.css` 끝 cockpit 덩이(또는 panel 전용 CSS) — **원본 구간은 안 건드린다**, 색은 `var(--md-…)`. 정적 시험 한 건.
- **N16 캐시**: 같은 주소에 v1 → v2 를 올리자 브라우저가 v1 의 `app.js` 등을 캐시에서 써서 로그인이 안 됐고 Cmd+Shift+R 뒤 됐다. 정적 파일에 `cache-control: no-cache` + `etag`(또는 `last-modified`) 로 재검증하게 하거나, 파일 이름에 판 번호를 붙여라. 시험 한 건. 실전에서 판을 올릴 때마다 사람이 강력 새로고침을 해야 하면 안 된다.

## 3.1 N17 의 방향 (사람 결정, 2026-09-15 01:30) — "자세히 볼 내용은 아니지만 칸 안에는 들어와야 한다"
지금은 `code.tool-input` 에 SDK 입력 JSON 을 그대로 넣는다(`detail: row.input`, 200자 요약). 사람이 원하는 것은 **한 줄 요약이 칸 폭 안에 들어오는 것**이지 JSON 을 읽는 것이 아니다. 고칠 자리 셋:
1. **줄 배치** — 요약은 이름 · 상태와 같은 줄이 아니라 **제 줄 하나를 통째로** 쓴다(`grid-column: 1 / -1` 이 지금 안 먹는 카드가 있다 — 원인을 찾아 시험으로 잡아라). 그 줄은 `display:block; min-width:0; white-space:nowrap; overflow:hidden; text-overflow:ellipsis` — **한 줄, 넘치면 줄임표**. 글자마다 줄바꿈(`overflow-wrap:anywhere` 단독)은 쓰지 않는다.
2. **내용** — JSON 대신 도구별 **사람 말 한 줄**(순수 함수 `glue.toolSummary(name, input)`, 시험): `Bash` → 명령의 첫 낱말 + 경로는 마지막 두 마디만(`grep … design/v2/ARCHITECTURE.md`) · `Read` · `Write` · `Edit` → 파일 이름(과제 폴더 기준 상대 경로) · `mcp__cockpit__reply` → `방 1 · 텍스트 앞 40자` · `mcp__cockpit__fetch_history` → `방 1 · #115 뒤 30건` · `Agent` → description 앞 40자 · `WebFetch` → 호스트 · 그 밖 → 키 이름 나열. 도구 이름도 `mcp__cockpit__` 접두를 떼고 `reply` · `fetch_history` 로.
3. **자세히** — 한 줄을 누르면(또는 `<details>`) 원래 JSON 요약 200자가 `white-space: pre-wrap` 으로 펼쳐진다. 기본은 접힘. `title` 속성에도 전문을 둔다.
색 · 글꼴 · 간격은 그대로 `var(--md-…)`. 정적 시험: cockpit 덩이에 `text-overflow: ellipsis` 가 있고 `.tool-input` 이 `nowrap`, `glue.toolSummary` 시험 여섯(도구별).
