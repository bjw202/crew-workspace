## 빗나간 뒤 적는 것
- **P7 위키 갱신 $0.58 (예측 ≤ $0.5)**: 위키를 처음 여는 판이라 페이지 뼈대(아는 것 · 근거 카드 · 모르는 것 · 조건 키 · 이력)를 다 만들었다. 둘째 카드부터의 갱신 값은 이번에 못 쟀다. 예측은 안 고친다. 4단계에서 카드 여럿일 때 다시 잰다.
- **P8 1~3층 62.5% (예측 ≥ 75%)**: 카드가 이상 자리만 싣고 정상 행을 안 실어 정상 행 물음(규격 이내 개체 · CH-2B · 공급사별)은 원본 csv 를 읽었다. 그리고 넷은 find.js 를 안 돌렸다. 카드 규격(전체 표 실을지)과 지침 강도 둘 다 후보. 예측은 안 고친다.

### T1.6 과 T1.M 의 어긋남 — 이렇게 푼다 (TASKS 보충, 2026-09-10)
`npm test` 는 **서버 없이** 도는 것만 담는다. setup.js 의 끝 조건은 `npm run test:server` 로 따로 두고, 그 시험이 스스로 임시 minidiscord 서버를 띄운다(빈 DB · 다른 포트 · 끝나면 내림. minidiscord 의 `scripts/e2e.mts` 가 같은 방식이다). 관문에서 meta 는 **둘 다** 돌린다. 서버를 못 띄우는 환경이면 `test:server` 는 "건너뜀"이 아니라 **실패**로 적는다.
