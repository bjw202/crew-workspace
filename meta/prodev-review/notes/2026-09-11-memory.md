# meta 세션의 기억 파일 여섯을 md 로 푼 것 (2026-09-11)

meta 세션의 기억은 `~/.claude/projects/…-meta/memory/` 에 있어 **기계에 묶여 있고 회사로 안 실린다.** 여기 여섯을 그대로 옮기고, 낡은 두 곳을 **[고침]** 으로 표시했다. 이 파일이 기억의 사본이고, 살아 있는 기억은 그날그날 바뀐다 — 두 곳이 갈리면 이 파일이 아니라 `HANDOFF.md` 와 `runs/` 가 진실이다.

- `name: crew-experiment-closed` · type project

## 5. prodev-direction — crew 다음은 비서 봇 하나 "prodev"

- `name: prodev-direction` · type project
- 2026-09-10 사람이 정했다: 과제마다 비서 봇 하나가 minidiscord 에서 PL 과 과제원 전원과 일한다. 설계 문서는 `../../../prodev/design/v<판>/` 다섯. 기획은 `../plans/2026-09-10-pl-assistant.md`, 상세 설계 `../plans/2026-09-10-prodev-design.md`, 고영혁 사례 `external-evidence-gonnector.md`.
- **[고침]** 기억 원문은 방 묶음을 일곱(본방·들이기·자료·리서치·특허·논문·보고)으로 적었으나 **방은 둘**(본방 · `/files`)이다 — ADR-022, 2026-09-10 저녁 사람 결정.
- **[고침]** 기억 원문은 대본 시험을 `replay.js`(서버 재생)로 적었으나 검색 관문부터는 **세션 대 세션**(ADR-029)이다. `MINIDISCORD_DB` 를 없는 경로로 주고 봇 폴더에서 `claude --setting-sources project,local`. `replay.js` 는 서버 판용으로 남아 있다.
- 사람이 정한 것: 카드 단위 = 실험 한 건 · 과제원 권한 = PL 과 같게(결재만 PL) · 봇 PC 인터넷 됨 · 과제마다 git 하나 · 위키는 카드마다 즉시 갱신(값을 재는 조건) · 세션은 상주하지 않는다.
- 진행: T1.M · T2.M(2차) · T3.M 통과(2026-09-10) → 검색 안정성 두 판(62.5% → 87.5% → 100%, 2026-09-11) → **진화하는 비서 관문 셋**(A 자리 10/10 · B 길 12/15 · C 짐, 2026-09-11, `design/v3/` ADR-031~037). 기록은 `../runs/`. 계획 원문은 `../plans/2026-09-11-handoff-evolution.md`.
- 자리 규칙: meta 는 예측을 먼저 적고 검수만 한다. prodev 는 관문 사이에만 worktree(`../prodev-wt-<이름>`) + PR 로 고친다. 관문 중에는 `../runs/IN-PROGRESS` 를 두고 훅이 worktree 편집까지 막는다. 정답지 · 채점표 · 예측은 prodev 세션에 주지 않는다. prodev 세션이 일하는 동안은 `notify_when_idle` 구독만 건다.
- 이 맥에서 더 시험하지 않고 회사로 옮겨 실전(T4)에 붙인다. 인수인계는 `../HANDOFF.md` 가 첫 자리.
