# 싱글 대조군 채점 기준 — 결과를 보기 전에 적는다

2026-09-09 10:22 UTC 에 싱글 세션을 띄웠다. **이 글은 그 결과가 나오기 전에 적는다.**
보고 나서 기준을 정하면 어느 쪽이든 이겼다고 쓸 수 있다.

## 조건을 어떻게 맞췄나

| | 다섯 봇 (회차 4) | 싱글 대조군 |
|---|---|---|
| 모델 | claude-opus-5 | claude-opus-5 (같음) |
| 입력 자료 | 수율 672행 · 설비 이력 48행 · 입고 검사 34행 | 같은 셋 |
| 아는 것 | 회차 3 결론 (두 후보로 좁혀졌고 못 가름) | 같은 것을 프롬프트로 줬다 |
| 물음 | 둘 (가려지나 / 다음 한 걸음) | 같은 둘, 문장까지 같게 |
| 산출물 | 공정 엔지니어가 혼자 읽을 보고서 | 같음 |
| 정답지 | 못 봤다 | 못 본다 (격리 폴더에 자료만 뒀다) |

**맞추지 못한 것 둘**을 미리 적는다. 판정할 때 봐줄 자리다.

- 봇 다섯은 회차 1~3 을 거치며 이 방의 위키·색인·원장을 쌓아 왔다. 싱글은 맨땅에서 시작한다.
  이건 싱글에게 불리하다.
- 봇 다섯은 규칙(6줄 서식·[추정] 표기·한계 적기)을 지침으로 받고 있다. 싱글은 프롬프트 한 번뿐이다.
  이것도 싱글에게 불리하다.

그래서 **싱글이 지면 그 차이의 일부는 조건 탓**이다. 싱글이 이기거나 비기면 그것은 깨끗한 결과다.

## 미리 정하는 판정 규칙

- **싱글이 7칸 중 6 이상이고 값이 다섯 봇의 절반 아래면** → 다섯 봇 구성은 이 과제에 과하다.
  `EVOLUTION.md` 의 S3 계획 "넷째 — 구성을 줄여 본다"를 실행에 옮긴다.
- **싱글이 4~5칸이면** → 교차 검토가 사는 값이 있다. 다만 다섯이 다 필요한지는 따로 본다
  (② 주 세션 + 검토 세션 하나를 다음에 돌려 가른다).
- **싱글이 3칸 이하면** → 다섯 봇 구성이 값을 한다. 이 경우에도 조율 비용 54% 는 따로 줄인다.

칸 수가 같으면 **값과 시간이 적은 쪽이 이긴 것**으로 본다.

## 표본이 하나다

싱글 세션을 한 번만 돌린다. 같은 프롬프트로 두 번 돌리면 다른 답이 나올 수 있다.
그래서 이 판정은 **방향을 가리키는 것**이지 확정이 아니다. 결과가 갈리는 자리면 두 번 더 돌린다.

# 2차 — 표본을 셋으로 늘리고 ②안을 더한다 (2026-09-09 10:49 UTC 시작)

1차에서 싱글이 5.5/7 · $3.90 · 8.4분이 나왔다. 표본이 하나라 확정할 수 없어 둘을 더 돌린다.
함께 S3 계획의 ② 안(주 세션 + 독립 검토 세션)도 돌린다.

## 돌리는 것 셋

| 이름 | 무엇 | 프롬프트 |
|---|---|---|
| `single-2` · `single-3` | 싱글 세션 | 1차와 **글자까지 같다** |
| `main-2s` + 검토 세션 | 주 세션 하나 + 다른 문맥의 독립 검토 하나 | 주 세션은 "검토를 통과해야 끝"이라는 줄만 더했다 |

검토자 프롬프트는 **봇이 실제로 쓰는 것**을 쓴다 (`bots/orchestrator/CLAUDE.md` 의 검토 서브에이전트 절).
그래야 "crew 의 검토 장치를 두 세션에 옮기면 어떻게 되나"를 재는 것이 된다.

## 미리 정하는 판정

채점표 일곱 칸은 위와 같다. 정답지도 `round-4-answer-key.md` 그대로다.

- **싱글 셋의 칸 수가 5~6에서 흔들리면** → 1차가 우연이 아니다. 싱글은 대체로 6칸 언저리다.
- **셋이 크게 갈리면**(예: 3칸과 7칸) → 싱글은 편차가 크다. 편차가 큰 것 자체가 다섯 봇을 쓰는 근거가 된다.
- **②안이 7/7 이면** → 다섯 봇이 하던 일을 두 세션이 한다. 나머지 셋(orchestrator·archivist·reporter)은
  과제 품질이 아니라 **기록과 조율**을 위해 있는 것이 된다. 그 값이 회차당 $73.53 인지 따로 판단한다.
- **②안이 싱글보다 안 나으면** → 검토 장치는 crew 의 구조 덕이지 검토 자체 덕이 아니다.

## 이번에도 미리 밝히는 불공정

싱글 셋과 ②안은 모두 **내가 정리해 준 프롬프트**를 받는다. 봇 다섯은 자기 방 파일에서 스스로 상황을 읽었다.
그만큼 대조군이 유리하다. 반대로 대조군은 위키·색인·원장을 **아무것도 남기지 않는다** — 다음 회차에 쓸 것이 없다.

값을 견줄 때 이 둘을 같이 적는다.
